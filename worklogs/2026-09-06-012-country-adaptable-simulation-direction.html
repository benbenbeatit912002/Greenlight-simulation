Country-adaptable simulation product direction

6 September 2026

Request

The user proposed focusing the project on enabling users from different countries to upload local climate data, fit the model to regional data and simulate greenhouse conditions.

Product direction

This is a stronger side-project direction: a country-adaptable greenhouse simulation platform. The product should separate weather ingestion, weather normalization, greenhouse configuration, model calibration and simulation. Uploading weather data alone supplies external forcing; it does not calibrate the GreenLight model. Calibration requires greenhouse-specific indoor observations, equipment capacities, crop information and an evaluation protocol.

Recommended wording

“Building a country-adaptable greenhouse simulation platform that enables users to upload local climate data, map it to the GreenLight input schema, and simulate greenhouse climate and crop responses under regional weather conditions.”

Current-status boundary

The current prototype uses Amsterdam 2010 as its verified model-weather source and validates Amsterdam-compatible Excel data as a preview. Country-specific custom-weather execution and parameter fitting are future milestones and should not be presented as completed features yet.

Files changed

Only this English work log and its index entry were added. No source code, model, dataset, research repository or external service was modified.

Validation

This was a product-direction and wording discussion. The recommendation is consistent with the current implementation and its disclosed limitations.
