Manual greenhouse dimensions and air-volume preview

3 October 2026

Request and outcome

The user requested manual greenhouse size and space design inputs. The existing 22-field panel already exposed floor/cover area and main/mean height. This update makes those inputs easier to discover, adds an optional rectangular length-by-width calculator, and previews main/top/total air volume for the settings draft.

Decisions and interaction

  • A bilingual Set greenhouse dimensions link jumps directly from the introduction to the settings panel. Its dimensions group opens initially; later language changes retain the user's group-open choices.
  • Length and width are entered in metres. Their product must satisfy the server-advertised floor-area bounds (currently 1–2000 m²). The explicit copy action updates only the floor-area draft; editing or copying does not reset the simulation.
  • Cover and roof-vent areas remain independent, as required by the model. The helper never invents a roof type, resizes vents or overwrites other settings. Existing dependent validation blocks incompatible combinations.
  • Main volume = floor area × main-compartment height. Top volume = floor area × (mean height − main height). Total volume = floor area × mean height. The interface explains that mean height is not maximum ridge height.
  • The volume cards are labelled as draft values, separate from the existing applied-settings summary. Invalid settings suppress the preview. Apply settings and initialize remains the only path from the form to a new model run.
  • Length/width are a calculator, not new scientific parameters or a 3D spatial simulation. They are intentionally not inferred from floor area and are cleared on page reload. Applied area/heights are restored from the server. Model defaults clears the calculator and settings draft without immediately changing the active run.
  • Native number inputs are reused across language changes and new-run rebuilds, preserving incomplete input such as 1e. Calculator input errors disable Copy, without invalidating unrelated valid model settings.

Read-only review

After visual inspection, the preview heading was clarified to Settings draft so it does not incorrectly imply that values matching the applied configuration are necessarily unapplied.
