Use English 24-hour schedule times

9 October 2026

Request

When the dashboard is in English, schedule inputs should not show locale-specific 上午/下午 clock labels.

Change

Replaced the browser-localized native time picker in the schedule editor with a text field that explicitly displays and accepts 24-hour HH:MM values. The browser locale can no longer render the field as AM/PM. Input validation still requires a valid 15-minute boundary; the instructions and column heading now identify the format in both languages. Existing schedule data and model time semantics are unchanged.

Changed frontend/controller-panel.js, frontend/translations.js, styles.css, index.html (cache version), this log and its index. No tests were requested or run. No GitHub changes were made.
