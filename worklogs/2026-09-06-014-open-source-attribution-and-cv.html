Open-source attribution and CV wording

6 September 2026

Request

The user asked whether modifying an open-source GreenLight project affects how the work can be presented in a CV.

Findings

  • The protected GreenLight-Gym2 checkout contains the GNU Affero General Public License, version 3 (AGPL-3.0), and its public README identifies the GreenLight-Gym2 project and citation.
  • The simulation repository currently has no selected software license, as disclosed in its README and CONTRIBUTING.md. Public visibility alone does not grant reuse permission for the user's original additions.
  • A CV may describe the user's own work as an application, dashboard or adapter built on GreenLight-Gym2, while crediting the upstream model and avoiding a claim that the model itself was created from scratch.
  • Publishing or hosting a modified AGPL-covered program requires retaining notices and following AGPL obligations. For network interaction, AGPL section 13 requires a prominent no-cost way for users to obtain the corresponding source. Exact obligations can depend on how code is copied, combined and distributed.

Files changed

Only this English work log and its index entry were added. No source code, model, dataset, research repository or external service was modified.

Validation

License facts were checked against the local upstream license, the local repository documentation and the official GNU AGPL text. This is a practical summary, not legal advice.
