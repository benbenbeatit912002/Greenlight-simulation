Manual simulator startup instructions

8 September 2026

Request

Explain how to manually start the local GreenLight simulator and whether it consumes Codex tokens or computer resources.

Instructions prepared

The user should open PowerShell, enter the dedicated Greenlight-simulation directory, set project-local runtime paths and launch the existing virtual environment with the full GreenLight-Gym2 engine on port 4173. The server remains in the foreground until Ctrl+C. The browser opens the local address http://127.0.0.1:4173/ on the same computer.

Resource explanation

Running the local simulator does not consume OpenAI or Codex tokens and does not use an API key. It uses local CPU memory and project-local logs/cache. The first dependency installation may use network bandwidth and disk space; starting an existing environment does not normally download dependencies.

Actions and validation

The local server was started once with the existing project virtual environment, Python -B, project-local runtime paths, the authorized read-only GreenLight-Gym2 source path, and --engine glgym --port 4173. No source files, protected repositories, research data or Git history were changed. This was an instruction and startup request, so no reviewer was needed.
