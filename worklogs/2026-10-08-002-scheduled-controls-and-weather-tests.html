Research and design decisions

  • Van Henten and Bontsema (2008), Open-loop optimal temperature control in greenhouses establishes a relevant greenhouse heating-profile reference. Its optimized strategy and model are not implemented or claimed to validate this dashboard.
  • Optimal control of greenhouse climate (1991) supplies earlier optimal-control context and cautions about weather/model error.
  • GreenLight-Gym2 already accepts external actuator actions and includes rule-based control. The inspected components did not include a ready daily schedule editor. GreenLight also includes prescribed constant-control examples (including a separate Van Henten 2003 model). Therefore, upstream open-loop execution is possible; this work supplies the scheduling UI/integration and evaluation workflow.
  • All six devices are explicitly scheduled. Commands hold until the next source-clock row and repeat daily; the first row is 00:00 and boundaries align to the fixed 15-minute model step. Thermal and blackout values mean percent closed.
  • Applying a schedule initializes a new run. Draft edits do not alter the active schedule. The existing automatic controller and scientific physics were retained; no approximation, optimizer, hidden safety override or regional calibration was introduced.
  • Fair comparisons require matching full-model identity, effective weather, greenhouse/initial state, scoring limits, resource accounting and duration. Whole-run metrics use duration-weighted end-of-step samples; exposure has 15-minute resolution and includes initialization transients.

Public weather and numerical results

NASA POWER hourly gridded data was obtained for Amsterdam winter, Almería summer and Taipei summer, with no API key or paid service. Each workbook contains 1,153 five-minute-format records over 96 hours. Source year is 2023 and the convention is fixed local standard time. Hourly values are held between source hours; missing values are rejected rather than invented.

Sky temperature is derived from downward longwave radiation; outdoor CO₂ is assumed to be 400 ppm; wind remains at NASA's 2 m reference height. Soil temperature retains upstream soilTempNl, a material limitation for foreign climates. Open-Meteo historical reanalysis and EnergyPlus EPW were researched as alternatives, but not downloaded.

Limits: 15–34 °C and 50–85% RH. Default greenhouse, seed 42, 288 steps per run. Each scheduled case was repeated in 48-step batches: indoor outputs, cumulative resources, climate metrics and command history matched one-step execution exactly. All nine runs had finite model states, no solver truncation, bounded controls, monotonic resources and exact endpoint stopping.

These are robustness checks, not predictive validation. The demonstration schedule is deliberately untuned and performed poorly. Taipei's scheduled temperature reached 44.64 °C; Amsterdam stayed below the chosen range. Automatic control also exceeded limits. Numerical success must not be interpreted as agronomic safety, optimality or regional calibration.

Raw downloads, processed records and complete snapshots are retained locally under .runtime/controller-weather/. Published source sidecars contain query URLs, units, provenance and response hashes; runtime output is ignored by Git.

Bounded independent review

A read-only reviewer completed one initial review and one follow-up, with no file writes or additional agents.

  1. Playback cap persisted after comparison: accepted. The target now clears at completion and when clearing a baseline. Live UI verification confirmed stopping at 480 matched steps, then ordinary playback advancing beyond 480.
  2. Controller reset errors bypassed reconnect handling: accepted. Confirmed non-mutating rejections preserve the active run; uncertain transport/model/revision failures invoke existing recovery. A second local API client advanced the revision; the UI then hid stale values, showed Reconnect, and recovered successfully.

The follow-up confirmed both fixes and reported no additional concrete regressions in the reviewed changes. The primary agent additionally exposed applied scoring limits to distinguish them from editable draft values.
